# Стиснення зображень: DCT 8×8 vs DWT (Haar)

Лабораторна робота з дисципліни «Розробка мультимедійних систем».
Програма стискає зображення у відтінках сірого двома методами та порівнює їх
за PSNR, часткою збережених коефіцієнтів і візуально: **Original | DCT | DWT**.

Зі сторонніх бібліотек використано лише NumPy (масиви, множення
матриць), Pillow (читання/збереження зображень) та Matplotlib (візуалізація).

## Встановлення

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Запуск

```powershell
python main.py image.jpg                    # вікно Original | DCT | DWT (p = 10%)
python main.py image.jpg --fraction 0.05    # інший рівень стиснення
python main.py image.jpg --experiments      # таблиця + збережені картинки в results/
```

Вхід: будь-який формат, який читає Pillow. Зображення переводиться у grayscale
і масштабується до 512×512.

## Структура

```
main.py              CLI, режими перевірки, експерименти
src/image_io.py      читання/збереження зображень
src/dct.py           DCT: матриця T, блоки 8×8
src/dwt.py           Haar DWT, багаторівневий розклад
src/compression.py   відкидання коефіцієнтів (top-p%)
src/metrics.py       MSE, PSNR, оцінки CR
src/visualize.py     порівняльне вікно
results/             вихідні зображення
```

## Алгоритм

**Загальна схема:** зображення → пряме перетворення → відкидання коефіцієнтів →
обернене перетворення → PSNR.

**DCT.** Блоки 8×8, віднімання 128, `F = T · f · Tᵀ`, обернене `f = Tᵀ · F · T`.
Матриця `T[i,j] = 1/√N` (i = 0), `√(2/N)·cos((2j+1)iπ/(2N))` (i > 0) ортонормована.

**DWT (Haar).** Пара → середнє `(a+b)/2` і піврізниця `(a−b)/2`;
обернене `s+d`, `s−d`. 2D: спочатку рядки, потім стовпці; далі розкладається лише LL
(3 рівні). Відновлення від найглибшого рівня до першого.

**Стиснення.** Залишається частка `p` найбільших за модулем коефіцієнтів (глобальний
поріг по всьому масиву), решта = 0. Однаковий механізм для обох методів дає чесне порівняння.

**Метрики.** `MSE = mean((I−Î)²)`, `PSNR = 10·log10(255²/MSE)`. Перед обчисленням
відновлене округлюється і обрізається до [0, 255].

- **Коефіцієнт стиснення ідеалізований:** `CR = 1/p` (усього коефіцієнтів / ненульових). Це гіпербола від частки,
  тому однаковий для DCT і DWT при однаковому `p`. Однак зміна реального розміру файлу різнитиметься від цього значення.

## Результати (512×512, DWT — 3 рівні)

| DCT   | 10%    | 10.00%    | 10.0     | 40.59    | 3.08        |
| DWT   | 10%    | 10.04%    | 10.0     | 36.39    | 3.07        |
| DCT   | 5%     | 5.00%     | 20.0     | 34.97    | 4.44        |
| DWT   | 5%     | 5.00%     | 20.0     | 31.73    | 4.44        |

## Висновки

1. Без відкидання відновлення ідеальне, перетворення реалізовано коректно.
2. DCT дає вищий PSNR при однаковій частці: +5.4 дБ (25%), +4.2 (10%), +3.2 (5%), +2.5 (2%);
   перевага зменшується зі зростанням стиснення.
3. `CR = 1/p` — ідеалізація; з урахуванням позицій і значень реальний виграш помітно менший.
