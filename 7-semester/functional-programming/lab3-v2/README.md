# lab3-v2 — обробка тексту підручника з програмування (Haskell)

## Завдання

Створити програму обробки тексту підручника з програмування на Haskell
з використанням типів «Символ», «Слово», «Пропозиція», «Розділовий знак» та ін.
У всіх завданнях з формуванням тексту табуляції та послідовності пробілів
замінюються одним пробілом.

**Завдання варіанту:** вивести всі пропозиції заданого тексту в порядку
зростання кількості слів у кожній з них.

## Швидкий старт

```
cabal run lab3-v2
```

Без аргументів програма читає `data/textbook.txt` і записує результат у
`data/result.txt`.

## Запуск

```
cabal run lab3-v2 -- [--counts] [вхідний_файл] [вихідний_файл]
```

| Аргумент        | Значення за замовчуванням | Опис                                                                     |
| --------------- | ------------------------- | ------------------------------------------------------------------------ |
| `вхідний_файл`  | `data/textbook.txt`       | текст у кодуванні UTF-8                                                  |
| `вихідний_файл` | `data/result.txt`         | файл перезаписується при кожному запуску                                 |
| `--counts`      | вимкнено                  | додає нумерацію, кількість слів у кожній пропозиції та підсумковий рядок |

## Текст підручника

Програма працює зі звичайним текстовим файлом UTF-8. Для роботи взято частину підручника (розділ «Частина II. Мова Haskell» (сторінки 64–137 друкованої нумерації)) _Функціональне програмування_ (Верес М.М., Галкін О.В.,
Демківський Є.О. та ін., КНУ, 2022):
<https://csc.knu.ua/media/filer_public/81/fc/81fc0d0a-d1e1-40ce-9f11-42df4a47b25a/funktsionalne_programuvannia.pdf>
який було переведено у txt формат та поміщено в `data/textbook.txt`.

## Типи даних

```haskell
type Symbol = Char
newtype Word        = Word [Symbol]
newtype Punctuation = Punctuation Symbol
data Token          = TWord Bool Word | TPunct Bool Punctuation
newtype Sentence    = Sentence [Token]
```

- **Символ** — один символ (`Char`).
- **Слово** — послідовність символів.
- **Розділовий знак** — один символ, що не входить до слова.
- **Лексема** (`Token`) — слово або розділовий знак. Поле `Bool` запам'ятовує,
  чи стояв перед лексемою пробіл у вихідному тексті (потрібно, щоб виведений
  текст відтворював вхідний: `Int->Int`, `C++`, `getName()`).
- **Пропозиція** — послідовність лексем.

## Алгоритм

1. **Читання.** Файл читається в UTF-8, службовий символ BOM (`U+FEFF`)
   на початку видаляється.
2. **Нормалізація пробілів** (`Normalize.normalize = unwords . words`).
   `words` розбиває текст за будь-якими пробільними символами
   (пробіл, табуляція, перенос рядка), `unwords` склеює результат
   одним пробілом. Переноси рядків теж вважаються пробілами, бо в підручнику
   пропозиції часто переходять на наступний рядок.
3. **Розбиття на лексеми** (`Tokenizer.tokenize`). Слово складається з літер,
   цифр і `_`. Символи `.`, `-`, `'`, `’` залишаються всередині слова,
   якщо стоять між двома символами слова (`3.14`, `будь-який`,
   `user.getName`, `Control.Monad.ST`). Усе інше — розділові знаки.
4. **Розбиття на пропозиції** (`Sentences.splitSentences`), див. нижче.
5. **Відсіювання** пропозицій без жодного слова.
6. **Сортування** за кількістю слів (`sortOn wordCount`). Сортування стабільне:
   пропозиції з однаковою кількістю слів лишаються в порядку з тексту.
7. **Виведення** (`Render.render`) із відтворенням пробілів вхідного тексту.

Кількість слів: числа, ідентифікатори та номери пунктів рахуються словами,
розділові знаки та оператори (`->`, `==`, `$`) — ні.

## Правила поділу на пропозиції

Завершальними знаками вважаються `.`, `!`, `?`, `…`. Знак завершує пропозицію,
лише якщо виконуються **всі** умови:

1. перед знаком немає пробілу (так код `forall a .` та `infixr 9 .`
   не завершує пропозицію);
2. після знака є пробіл або кінець тексту (так код `x!(i,k)` не завершує);
3. наступне слово (після відкриваючих дужок і лапок) починається з великої
   літери або це номер пункту списку виду `1.`, `2)` перед словом з великої
   літери.

Додатково:

- кілька завершальних знаків підряд (`?!`, `...`) і закриваючі дужки та лапки
  після них (`.)`, `!»`) входять до тієї самої пропозиції;
- крапка відразу після числа на початку пропозиції — це номер пункту списку
  (`1. Текст`), а не кінець пропозиції.
