# Паралельне обчислення інтеграла (Haskell)

Обчислення J(A, B) = ∫ₐᵇ f(x) dx із точністю ε методом Сімпсона. Точність контролюється правилом Рунге: кількість підінтервалів подвоюється, доки `|I₂ₙ − Iₙ| / 15 < ε`. Відрізок [A, B] ділиться на `k` частин, які рахуються незалежно.

## Версії

| Функція         | Підхід                    | Тип   |
| --------------- | ------------------------- | ----- |
| `integrateSeq`  | послідовно                | чиста |
| `integratePar`  | sparks, `parMap rdeepseq` | чиста |
| `integrateConc` | `forkFinally` + `MVar`    | `IO`  |

Цикл Рунге (`runge`) спільний для всіх версій.

## Функція, що інтегрується

Для вимірювань взято навмисно «важку» функцію (сума 200 синусів), щоб обчислення тривало помітний час:

```haskell
f :: F
f x = sum [ sin (fromIntegral j * x) / fromIntegral j | j <- [1 .. 200 :: Int] ]
```

Параметри: `A = 0`, `B = 10`, `ε = 1e-10`, `k = 64` відрізки. Усі вони задаються в `app/Main.hs`.

## Запуск

Збірка йде з `-threaded`, а в `.cabal` задано `-with-rtsopts=-N`.

```powershell
cabal run
```

Без додаткових прапорців програма використає **всі логічні ядра**.

Щоб задати кількість ядер вручну, прапорці для runtime передаються після `--`:

```powershell
cabal run integral-par -- +RTS -N8
```

- `-N8` означає 8 capabilities, тобто до 8 потоків ОС, що одночасно виконують Haskell-код. `-N1` це одне ядро, `-N` без числа це всі ядра.
- `-s` додатково виводить статистику (CPU-час, кількість spark-ів, GC).

## Результати

Усі версії дали `J = 2.379701487943`.

| `-N` | sequential | parMap        | forkIO + MVar |
| ---- | ---------- | ------------- | ------------- |
| 1    | 939 мс     | 930 мс        | 949 мс        |
| 8    | 936 мс     | 261 мс (3.6×) | 176 мс (5.4×) |
| 12   | 969 мс     | 216 мс (4.3×) | 134 мс (7.1×) |

## Висновки

- Паралельні версії дають той самий результат, змінюється лише час.
- Прискорення зростає з `-N`, але не лінійно (гіперпотоки, послідовне додавання результатів).
- `forkIO` швидша за `parMap`: за `+RTS -s` 405 із 640 spark-ів були fizzled, тобто їх обчислив основний потік раніше, ніж їх узяв вільний.

> Для свого варіанту підставте `f`, `A`, `B`, `ε` у `app/Main.hs` і перезапустіть вимірювання.
